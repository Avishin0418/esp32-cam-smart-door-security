# ESP32-CAM Smart Door Security System

This project transforms an ESP32-CAM into a smart security device:

✅ Captures and streams live camera footage  
✅ Can trigger relays for door locks or alarms  
✅ Can play voice messages via SD1820-S16 module  
✅ (Optional) Send snapshots over WiFi

## Hardware

- ESP32-CAM  
- JQC3F-05VDC-C relay module  
- SD1820-S16 voice playback module

## How to Use

1. Connect ESP32-CAM and configure pins  
2. Upload `esp32_cam_door_security.ino` using Arduino IDE  
3. Connect to WiFi and access the camera server

## Requirements

- Arduino IDE  
- ESP32 board definitions  
- ESP32-CAM module
